# OTLI
> JVM Lab. Java, Kotlin, Scala, and Groovy, and many of the most popular frameworks for each.

The name *Otli* comes from the Nahuatl word for "path" or "road," symbolizing the journey of learning and exploring the vast landscape of JVM languages and frameworks.

---
## Overview
OTLI is a comprehensive learning platform designed to help developers master the JVM ecosystem. It provides tutorials

---

## Features
- **Multi-Language Support**: Learn Java and Kotlin in one place.
- **Framework Tutorials**: Explore popular frameworks like Spring, Quarkus, Jetpack Compose, and more.
- **Hands-On Labs**: Engage in practical exercises to reinforce your learning.

### MODULES
- core → Here you will see examples on different native Java and Kotlin topics and some external libraries that do not change the vanilla language behavior.
- jvfx → This module contains examples and operation of the framework for FXML-based graphical interfaces, that is, Java Fx.
- quarkbit → Quarkus, all my learning about this web framework is here.
